# CS2 · Лимит FPS в матче

[autoexec.cfg](autoexec.cfg) содержит одну команду — `fps_max 0`. Она снимает ограничение частоты кадров во время матча. Лимит меню, разрешение, качество изображения и настройки задержки сохраняют свои значения. Если игра работает ниже прежнего лимита, снятие потолка само по себе вряд ли даст прирост.

## Применение

1. В консоли CS2 введи `fps_max` и запиши исходное значение для отката.
2. Через Steam открой установленные файлы CS2 и перейди в `game/csgo/cfg`. Если `autoexec.cfg` отсутствует, скопируй туда файл из репозитория. Если у тебя уже есть свой конфиг, сохрани его копию и измени или добавь в нём только команду `fps_max`.
3. В открытой игре введи `exec autoexec`. Затем проверь значение командой `fps_max` — консоль должна показать `0`. При следующем запуске игры конфиг загрузится автоматически.

## Откат

Если у тебя был свой `autoexec.cfg`, восстанови исходную строку или удали добавленную. Если файл был создан специально для этой команды, удали его. Затем введи в консоли `fps_max` со своим прежним значением, например `fps_max 400`.

Для случая, когда файл был создан с нуля, есть [скрипт отката](rollback_cs2.py) для Windows и Python 3.8+. Скопируй [before.example.json](before.example.json) в `before.json` рядом со скриптом, укажи реальные пути и свой исходный лимит. Если у тебя уже есть локальный `before.json` от первоначальной настройки, используй его. Запусти [Откат CS2.cmd](Откат%20CS2.cmd). При открытой игре скрипт подскажет команду для текущего сеанса.

## На каком ПК проверено

В [отчёте](REPORT.md) собраны результаты проверки Core i5-12400 с Intel UHD 730 и DDR4-3200. В [diagnostics](diagnostics/) лежат два скрипта для чтения параметров Intel и Windows. Исходная сцена — Training.01 с 15 ботами. Замер FPS после изменения и сравнение задержки ввода не проводились.
